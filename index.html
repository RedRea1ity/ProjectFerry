开盘须知

  1. 01
    通用游戏汉化

    选游戏目录或镜像，先看能不能读、能不能写回。支持的格式可导出双语表，人工校对后重刷，不再消耗翻译额度。

  2. 02
    Minecraft 模组汉化

    扫描整合包的中文缺口，译文单独写进资源包。已有人工汉化优先，桥接模组另行下载。

  3. 03
    动手之前先留原档

    早期测试版的适配程度因游戏而异。先在副本上体检和试写，尤其是老游戏、掌机与移动端镜像。

盘内 / README

随盘手记

从方块世界，到旧游戏。

2.0 把 Minecraft 和通用游戏分成两条工作线。吉里吉里、RPG Maker、Godot，以至 PC-98 磁盘镜像，都有了各自的读写路径。Android 和掌机是可处理的游戏格式，不是本工具的安装平台。

本版 README 更新摘录
  • ⚠️ 稳定性警示（比 v2.0.0-alpha.4 更不稳定）：本版为全线覆盖塞班全世代与黑莓全世代的早期实验测试版，新增 .sisx TLV/zlib 重压缩、Qt .qm 重建与黑莓 .cod/.jad/.bar 协议回写未经大规模实机验证，稳定性低于 v2.0.0-alpha.4，仅供尝鲜测试与提交反馈；处理原游戏文件前请务必备份，求稳请优先使用正式版或 v2.0.0-alpha.4。
  • 内置 Symbian 9+ .sisx (0x10201A7A) 的 TLV SISCompressed (0x0018) zlib 数据流自动解包与重压缩，无需外部 SISContents 或 unsis 即可直接深入 .sisx 压缩块内部抽取并回写 .cn.sisx；
  • 新增塞班^3 / 安娜 / 贝拉（以及 PC Qt 游戏）通用的 Qt .qm 编译语言包（魔数 3C B8 64 18...）解析器与 UTF-16BE 任意长度重建器，以及 Qt Quick .qml (qsTr(...)) 抽取与回写。
